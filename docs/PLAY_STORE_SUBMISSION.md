# Play 스토어 제출 준비 (2026-09-14)

`docs/PLAY_STORE.md`가 TWA 빌드 절차 전체를 다룬다면, 이 문서는 **실제 스토어 등록 폼에
그대로 붙여넣을 수 있는 문구·데이터**와 **이번 세션에서 끝낸 것 vs 사용자가 직접 해야
하는 것**을 정리한다.

## 1. 이번 세션에서 끝낸 것

| 항목 | 내용 |
|---|---|
| 개인정보처리방침 페이지 | `/privacy` 라우트 신설(`src/screens/PrivacyPolicyScreen.tsx`), 로그인 전/후 양쪽에 등록해 **비로그인 상태(스토어 심사자 포함)에서도 열람 가능**. 배포 완료, 실제 URL로 검증함 |
| 앱 내 개인정보처리방침 링크 | 로그인 화면 하단, 설정 화면 고객센터 카드에 링크 추가 |

## 2. 사용자가 직접 해야 하는 것 (순서대로)

이 부분은 Google 계정·결제·GUI 상호작용이 필요해 코드로 대신할 수 없다. `docs/PLAY_STORE.md`
2장의 상세 절차를 따르되, 순서는 다음과 같다.

1. **서명 키 생성** (`docs/PLAY_STORE.md` 2-2) — `cd android && npx @bubblewrap/cli init --manifest ./twa-manifest.json`. 키스토어 비밀번호 반드시 백업.
2. **로컬 지문을 assetlinks.json에 등록 + 재배포** (2-3).
3. **AAB 빌드** (2-4) — `npm run android:build`.
4. **Google Play Console 개발자 계정 등록** ($25, 최초 1회, 아직 없다면).
5. **Play Console → 앱 만들기** → 아래 4장 문구를 그대로 붙여넣기.
6. **비공개 테스트(내부 테스트) 트랙에 AAB 업로드.**
7. **앱 서명 지문 확인 → assetlinks.json에 추가 → 재배포** (`docs/PLAY_STORE.md` 3장 4~5번, 이거 빠뜨리면 앱에 URL 바가 보임).
8. **스토어 등록정보 작성**: 아래 4장 문구 + `docs/play_store_assets/feature_graphic.png` + `public/screenshots/shorts-narrow.png`, `shorts-wide.png` 업로드.
9. **데이터 보안(Data safety) 설문**: 아래 5장 표 그대로 입력.
10. **콘텐츠 등급(IARC) 설문**: 아래 6장 답변 그대로 입력.
11. **타겟 연령층**: "만 13세 이상"으로 선택 권장(이유는 6장 참고). "주로 아동 대상" 선택하지 말 것 — 그러면 Google이 훨씬 엄격한 아동 정책(광고·데이터수집 제한 등)을 적용해 친구/닉네임 검색 같은 기존 기능과 충돌할 수 있음.
12. **개인정보처리방침 URL** 입력란에: `https://5minuatestudy.ehddn5252.workers.dev/privacy`
13. 심사 제출.

> 심사 제출 전, `?devlogin=1` 없이 정식 배포 URL을 새 시크릿 창으로 열어 테스트 로그인
> 버튼이 안 보이는지, `/privacy`가 로그인 없이 열리는지 마지막으로 한 번 더 눈으로 확인할 것.

## 5. 데이터 보안(Data safety) 설문 매핑

실제 코드(인증/Supabase 동기화/Gemini 프록시/IndexedDB 녹음)를 감사해 작성함 — 추측 없음.

| 데이터 유형 | 수집 여부 | 공유 여부 | 목적 | 비고 |
|---|---|---|---|---|
| 이메일 주소 | 수집함 | 공유 안 함 | 계정 관리, 앱 기능 | Google 로그인 시 획득, Supabase에 저장 |
| 이름(닉네임/표시 이름) | 수집함 | **다른 사용자와 공유**(선택) | 앱 기능 | 친구로 연결된 상대에게만 표시. 삭제 가능(사용자가 언제든 변경) |
| 앱 활동(학습 목표, 세션 기록, 퀴즈/답안, 오답, 배지) | 수집함 | 공유 안 함 | 앱 기능 | Supabase에 저장, 기기 간 동기화 목적 |
| 음성 또는 사운드 녹음 | 수집함(단, **일시 처리**로 표시) | 공유 안 함 | 앱 기능 | 기본은 기기 내(IndexedDB)에만 저장. "AI 피드백" 기능을 직접 실행할 때만 서버 프록시를 거쳐 Google Gemini API로 전송·평가 후 폐기(서버 영구 저장 없음) — "일시적으로 처리됨(ephemeral)" 옵션 사용 |
| 기기 또는 기타 ID | 수집 안 함 | - | - | 분석/광고 SDK 없음 |
| 앱 상호작용(분석/충돌 로그) | 수집 안 함 | - | - | Analytics/Crashlytics/Sentry 등 SDK 미사용 확인됨 |
| 광고/마케팅 목적 데이터 | 수집 안 함 | - | - | 광고 SDK 없음, 이 앱은 광고 없음 |

**보안 관행 체크박스**:
- 전송 중 데이터 암호화: 예 (HTTPS/TLS, Cloudflare + Supabase 모두 HTTPS)
- 삭제 요청 가능 여부: 예 — `/privacy` 페이지 내 "계정·데이터 삭제 요청하기" 이메일 링크로 요청 (자동화된 인앱 삭제 버튼은 없고, 이메일 확인 후 수동 삭제 방식임을 그대로 기재)
- 독립 보안 검토: 아니오

## 6. 콘텐츠 등급(IARC) 설문 예상 답변

| 질문 | 답변 | 근거 |
|---|---|---|
| 폭력적 콘텐츠 | 없음 | 학습 앱, 폭력 요소 없음 |
| 성적 콘텐츠 | 없음 | 없음 |
| 욕설/불쾌한 언어 | 없음 | 앱이 직접 제공하는 콘텐츠 없음 |
| 도박 관련 콘텐츠 | 없음 | 없음 |
| 규제 물질(주류/담배/마약) 언급 | 없음 | 없음 |
| 사용자 생성 콘텐츠(UGC) 공유 | **있음** | 사용자가 목표 주제·참고 자료를 자유 텍스트로 입력하고, 친구에게 공유 가능 — 이론상 부적절한 텍스트 입력 가능성 있음 |
| 사용자 간 상호작용(채팅 등) | **있음(제한적)** | 친구 닉네임 검색, 학습 콘텐츠 공유, 숙제 코멘트(학원 기능, 현재 비활성화) — 자유 형식 채팅은 없음 |
| 위치 공유 | 없음 | 위치 API 미사용 |
| 개인정보 공유(사용자 간) | 있음(닉네임만) | 이메일은 노출 안 됨, 표시 이름만 친구 간 공개 |
| 디지털 구매 | 없음 | 무료, 인앱 결제 없음 |

**권장 결과**: "전체 이용가"에 가깝지만, UGC 자유 텍스트 입력과 사용자 간 콘텐츠 공유가
있어 IARC 설문에서 자동으로 "만 12세" 또는 "만 13세 이상" 등급이 나올 수 있다 — 이는
정상이며 임의로 낮춰 답하지 말 것(설문에 사실대로 답하면 IARC가 알아서 적절한 등급을
매긴다).

## 7. 참고 — 이후 유지보수

- 웹 콘텐츠(문구/기능)만 바꾸는 배포는 `npm run build && npx wrangler deploy`만 하면
  설치된 앱에도 그대로 반영됨(TWA 특성). 스토어 재제출 불필요.
- `twa-manifest.json`(아이콘/이름/네이티브 설정)이 바뀔 때만 `npm run android:release`로
  새 AAB를 만들어 Play Console에 다시 업로드해야 한다.
- 개인정보처리방침 내용이 바뀌면(예: 새로운 제3자 서비스 연동) `PrivacyPolicyScreen.tsx`의
  `EFFECTIVE_DATE`도 함께 갱신할 것.
