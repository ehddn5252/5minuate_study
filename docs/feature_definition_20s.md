### F-25: 듣는 5분 학습 — 오디오 퍼스트 모드

**한 줄 설명:** 오늘의 핵심 요약과 퀴즈 문항·선택지를 브라우저 내장 음성 합성(Web Speech API `SpeechSynthesis`)으로 낭독한다.

**페르소나:** 지원(이동 중 산발적 학습), 도윤("공부용 앱" 진입장벽 완화 — 화면 안 보고 그냥 들으면 됨), 수아(화면 못 보는 구간까지 학습 확장, 쇼츠와 채널이 달라 안 겹침)

**시스템 처리**
1. 듣기 모드 ON 시, 이미 생성된 요약 텍스트(F-08)를 문장/불릿 단위로 분리해 `SpeechSynthesis` 큐에 등록.
2. 테스트 화면 진입 시에도 유지되면 문항+선택지를 순서대로 낭독.
3. 답변 입력은 기존 UI 그대로(음성 인식 입력은 범위 밖).
4. 신규 Gemini 호출 없음 — 이미 만들어진 텍스트를 낭독만 함.

**동작 규칙**
- 오디오는 낭독 채널일 뿐, 콘텐츠 생성·문항 수·정오답 판정 로직에 영향 없음
- 화면 전환/탭 이탈 시 낭독 즉시 정지
- 자동 재생 없음(사용자가 직접 재생 눌러야 시작)

**검증 조건**
- [ ] 듣기 모드 ON 시 요약이 순서대로 낭독됨
- [ ] 테스트 화면에서 문항+선택지 낭독
- [ ] 일시정지 후 재생 시 중단 지점부터 이어짐
- [ ] Gemini 호출 횟수 변화 없음
- [ ] `SpeechSynthesis` 미지원 브라우저에서 토글 미노출
- [ ] 화면 이탈 시 낭독 즉시 멈춤

**기존 기능과의 관계:** F-08/F-11/F-12가 만든 텍스트를 낭독 채널로 재사용. `gemini.ts`/`contentPool.ts`/`questionBank.ts` 변경 없음. Web Speech API만 사용해 기술 스택 변경 아님.

### F-26: 오늘의 학습운 — 랜덤 데일리 훅

**한 줄 설명:** 학습 시작 직전, 성과·능력치와 무관한 가볍고 랜덤한 한 줄 문구를 보여준다.

**페르소나:** 도윤(예측 불가능한 소소한 자극에 오래 남는 유형), 지원(선택 피로를 가볍게 대신 규정), 수아(로그인 후 낙차 완화)

**시스템 처리**
1. 사전 정의된 문구 뱅크(20~30종)에서 오늘 날짜를 시드로 1개 선택 — 같은 날 재방문 시 동일 문구, 다음 날 자동 교체.
2. 학습 화면 진입 직전/상단에 짧게 노출.
3. 실시간 생성 호출 없음(정적 배열에서 즉시 선택).
4. 하루 최초 진입 시 1회만 노출(목표별 반복 노출 안 함).

**동작 규칙**
- 성과/능력치/랭킹과 무관한 순수 재미용, 검증 불가능한 과장 표현 금지
- "운세/타로" 프레이밍 대신 "오늘의 공부 컨셉/톤 제안" 수준으로 절제
- 매번 닫기(X)로 즉시 스킵 가능
- F-20(알림 문구 뱅크)과 문구 뱅크를 분리 관리 — 노출 시점·목적이 다름

**검증 조건**
- [ ] 하루 첫 학습 시작 시 랜덤 문구 노출
- [ ] 같은 날 재방문 시 동일 문구 유지(날짜 시드)
- [ ] 다음 날엔 다른 문구 노출 가능
- [ ] 문구 노출 중 Gemini 호출 없음
- [ ] 성과/능력치/순위 관련 표현 없음
- [ ] 스킵 시 즉시 학습 화면 진입

**기존 기능과의 관계:** F-20의 "정적 문구 뱅크 + 랜덤 선택" 패턴을 재사용한 완전 신규 기능. 새 유틸 파일 1개로 충분. 알림/스트릭/뱃지/정체성 서사(F-22)와 노출 시점·목적이 달라 안 겹침.

### F-27: AI 케미 학습메이트 — 톤 커스터마이징

**한 줄 설명:** 학습 콘텐츠(요약·해설)의 AI 말투를 사용자가 목표 단위로 선택(다정한 친구/예능 자막체/담백한 선배).

**페르소나:** 수아(쇼츠의 하이텐션 톤과 학습 톤의 낙차를 직접 이어붙임), 도윤("힙함"이 리텐션 결정 — 예능 자막체로 덜 "공부 같음"), 지원(내가 고른 성격의 AI가 매일 같은 어조로 말해주는 관계감)

**시스템 처리**
1. 목표 생성 화면에 "AI 말투" 선택 UI 추가(`practicalMode` 토글과 같은 위치/형식).
2. 선택된 톤을 `gemini.ts` 프롬프트에 `LEVEL_DESC`/`PRACTICAL_MODE_INSTRUCTION`과 동일한 패턴으로 `TONE_INSTRUCTION` 한 줄 추가 삽입. 응답 JSON 스키마 변경 없음(어조만 변화).
3. 자유 대화형 챗봇 UI는 만들지 않음(호출 급증 위험 차단).

**동작 규칙**
- 톤은 목표 단위로 고정(`practicalMode`와 동일 패턴), 세션마다 변경 불가
- 기본값(미선택)은 기존과 동일한 중립 톤 — 회귀 없음
- 비기본 톤은 `practicalMode`와 동일하게 공유 풀/문제 뱅크를 건너뛰고 항상 개인 Gemini 호출로 생성(캐시 오염 방지)
- 톤 프리셋 3종으로 제한(선택 마찰 최소화)
- F-24(세대 톤 분리, UI 카피 레이어)와는 다른 레이어 — F-27은 AI 생성 콘텐츠(요약/해설) 톤. 두 레이어는 독립적으로 공존 가능

**검증 조건**
- [ ] 목표 생성 시 톤 3종 중 선택 가능
- [ ] 선택한 톤이 요약/해설 문체에 반영
- [ ] 기본 톤 선택 시 기존과 동일한 문체로 회귀 없이 생성
- [ ] 비기본 톤 선택 시 공유 풀/문제 뱅크를 거치지 않고 항상 새로 생성
- [ ] 자유 텍스트로 AI에게 질문 입력하는 UI 없음
- [ ] 톤 선택이 하루 20회 호출 한도 자체를 변경하지 않음

**기존 기능과의 관계:** F-01 옵션 확장 + F-08/F-11 프롬프트 확장. `Goal` 타입에 `mateTone?: 'friendly' | 'hype' | 'plain'` 필드 1개만 추가. 공유 풀 제외 분기는 F-21의 `practicalMode` 처리 코드 경로를 재사용·확장.

## 우선순위 — 현재 스택 기준 구현 난이도 낮은 순

| 순위 | 기능 | 난이도 근거 |
|---|---|---|
| 1 | F-26 오늘의 학습운 | 정적 문구 뱅크+날짜 시드 랜덤 선택뿐. 새 화면·API·스키마·Gemini 호출 없음 |
| 2 | F-25 듣는 5분 학습 | 순수 클라이언트(Web Speech API), 백엔드 변경 없음. 다만 두 화면에 재생 컨트롤 UI 필요 |
| 3 | F-27 AI 케미 학습메이트 | `Goal` 스키마 추가 + UI 추가 + 프롬프트 확장 + 캐시 우회 분기까지 가장 많은 지점을 건드림 |

### F-27과 하루 20회 Gemini 호출 제한의 관계
호출 총량은 불변(콘텐츠 1건=호출 1회, 톤 지시문은 같은 호출 안에 추가되는 것뿐). 비기본 톤 선택 시 캐시 우회로 그 사용자의 호출이 늘지만, 동시 진행 목표 상한 3개(F-01)를 고려하면 최악의 경우도 하루 3회 수준으로 20회 한도에 위협 없음. F-21에서 이미 감수 중인 트레이드오프와 동일.
